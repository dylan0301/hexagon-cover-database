\section{Technical Verification Roadmap}
\label{sec:appendix-roadmap}

The body gives the complete geometric routing and identifies the terminal
certificate used in every branch.  The appendices then separate three tasks
that must not be conflated:

\begin{enumerate}
\item \emph{geometric extraction:} prove that a routed configuration produces
a real parameter record in a named domain;
\item \emph{optimization statement:} define only the real variables, branch
domains, recurrences, and objective sign;
\item \emph{verification:} prove that objective sign, branch by branch.
\end{enumerate}

The proof is the body together with these verification modules and the
formally incorporated electronic supplements.  The body alone is not asserted
to prove the calculation lemmas.

Appendix~\ref{sec:strategy2-optimization-problems} is the normative
formalization interface for the scalar Strategy~2 calculations.  Every
registered domain is an explicit finite union of real cells, including the T3,
adjacent-rescuer, and Vd cases.  Section~\ref{sec:strategy2-pure-theorems}
proves the objective sign with the universal quantifier stated in each problem.
Appendix~\ref{sec:strategy2-parameter-bridges} then proves only domain
membership and objective identities for geometric configurations.

Polynomial expansions, root selection, rational parametrizations,
monotonicity checks, Gram reductions, and Bernstein identities occur only in
the verification appendices or in the exact electronic supplements identified
by repository path, Git blob, and authenticated transcript.  A machine
verifier is used as part of the proof only where its exact input and algorithm
are formally incorporated; a bare script invocation or claimed output is not
treated as a proof.

\paragraph{Strategy 2 module boundary.}
Appendix~\ref{sec:strategy2-parameter-bridges} is the sole mixed
geometry--analysis dictionary.  Appendix~\ref{sec:strategy2-optimization-problems}
contains the geometry-free problem registry, including the explicit T3,
rescuer, and Vd cells.  Section~\ref{sec:strategy2-pure-theorems} is the
universal proof owner.  The file \texttt{04\_strategy2\_verification.tex} is
an input-only wrapper; its numbered \texttt{04e\_strategy2\_verification\_*}
modules separately own the registered applications and the preserved exact
calculation sections.
