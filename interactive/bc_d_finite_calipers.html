The proof behind the display

For arbitrary 0 < x ≤ y < 1, 0 < r ≤ min(y,1−y), and 0 < t ≤ x/2, four calipers exceed one by elementary inequalities. Thus the set fails to fit a closed unit triangle exactly when the remaining caliper exceeds one. This threshold criterion is independent of capacities and does not assert that the remaining caliper is always the minimum. The remaining edge Gᵧ(rV₂), with k = y−r, has side

[r+t+max{1/2, 1−x(1−k)}] / √(1−k+k²).

The sliders show the capacity instance. The coupled inequality 2(r+t) > (1−y+r)(2x−y+r) excludes it. Its proof uses the reusable slack-sensitive envelope below, plus the stated branchwise concavity reduction.

m = min(a,b), δ = 1−a−b, m ≤ 3/8
1−C₀(a,b) ≥ max{m/2−2m²/5, m−[(5+4m)/(5−4m)]δ}.

Original-cover forcing and the neighbor correction

Set x=B₀, y=1−A₁, z=B₃. Apply C±(a,b) ≤ 1−min(a,b) ≤ C₀(a,b) at each triangle’s own pair. The clipped-path corollary to total-endpoint forcing gives safe radius min{1−C₀(Aᵢ,Bᵢ),Aᵢ₋₁,Bᵢ₊₁}. The safe witnesses are rV₂ and min(t,A₃)V₄. If A₃ ≥ t, use this five-point theorem. Otherwise A₃ ≥ 1−y and |Gᵧ−A₃V₄|² ≥ 1+(1−y)(2−y) > 1. This correction is not omitted or treated as a cross-pair capacity comparison.

For 0<s,v<1 the smaller quadrilateral has four caliper sides

1/√(1−v+v²), 1+s(1−v), 1/√(1−s+s²), 1+v(1−s).

All four exceed one. At a=0 or s≥1 a pair of points has distance at least one. Neither a≤ε nor s≤1 is required for the full theorem. The original supplier adapters still need to force the points and establish the ratio.
