# Minimum Enclosing Equilateral Triangle Tools

Status: Reference

For a compact set $K$, the finite-point routes use the optimized enclosing
side length $\Lambda(K)$.

The active enclosing-triangle tools are:

- [`2607`](2607_minimal_enclosing_equilateral_quadrilateral_lemma.md):
  contact patterns for a convex quadrilateral;
- [`2608`](2608_residual_hull_finite_enclosure_principle.md):
  type-aware radial witnesses, common-pair domination, the disk-plus-point
  formula, and the complementary-gap obstruction;
- [`2609`](2609_simplified_finite_enclosure_lemmas.md):
  disk--finite-set calipers, the shortened CE2 two-gap proof, the half-edge
  one-third radial envelope, and the common rescuer-tail budget.

The active one-gap all-Vd0 enclosure theorem is the transverse seven-point
certificate
[`4103`](../../4XXX_CE1CE2/41XX_Nplus1/410X_all_Vd0_new/4103_transverse_seven_point_enclosure.md).
