# Old Proof Archive

Status: Historical

This directory preserves proof routes that are no longer part of the active
dependency graph or manuscript build.  Archival material must not be cited as
an active proof owner unless it is separately reviewed and reintroduced.

The first retained package is `strategy2_radial_propagation/`, containing the
old assembled Strategy 2 radial-propagation chapter, its scalar-verification
sources, provenance metadata, and explanatory interfaces.

The numbered geometric and casewise sources that still belong to the live
repository remain at their established paths.  They are not duplicated or
moved merely to create this archive.
